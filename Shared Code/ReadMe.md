## User Guide
This code is a demonstration of event-triggered cooperative online learning for multi-agent system in time-varying leader-follower formation control.

The code compares the proposed method with existing cooperative learning framework.
The ingle comparison is in
- ET_MAS_GP_Leader_OnceComparison_Test.m
And the Monte Carlo test is in
- ET_MAS_GP_Leader_MontCarlo_Test.m
with result postprocessing.
